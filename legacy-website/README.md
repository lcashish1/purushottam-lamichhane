# Previous website files

This folder preserves earlier website experiments and the retired portfolio migration workflow. The current professional portfolio is maintained at https://lcashish1.github.io/.

Archived items:
- `old/` — previous experimental HTML, CSS, JavaScript and PHP prototypes
- `html/` — unused shared header/footer prototypes
- `.github/ISSUE_TEMPLATE/` — unused issue templates from the former website
- `.github/workflows/import-technical-projects.yml` — completed project migration maintenance script

Temporary editor swap files (`*.swp`) were intentionally excluded; they are not usable project deliverables and can contain fragments of editor sessions. This archive is historical, not a running server-side application.
